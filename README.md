# Arabic Word Adventure

Picture-and-sound Arabic games for young kids (KG1 and KG2).

- **Arabic Letters**: all 28 letters, about 10 common words each, Watch mode and a different game for every letter with a climbing-ladder reward: https://rashadtc.github.io/arabic-word-adventure/letters/
- **Arabic Word Adventure** (KG1 class review words): https://rashadtc.github.io/arabic-word-adventure/

Tap a picture to hear the word. Photos come from Wikipedia / Wikimedia Commons (credits inside each app).
